# taxel-lp

Taxel（税理士事務所向けAI経営支援クラウド）のコーポレートサイト / LP。

- 公開先: https://taxel.biz
- 構成: 静的HTML（Tailwind CDN + Google Fonts）。ビルド不要
- ページ: トップ / 会社概要 / ブログ一覧 / コラム記事10本 = 全14ページ

## 更新方法

HTMLを直接編集して push すると、Netlify が自動でデプロイする。
